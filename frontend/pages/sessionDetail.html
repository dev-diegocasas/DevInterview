Transcripción de la Sesión

smart_toy

¿Podrías explicar la diferencia entre useEffect y useLayoutEffect? ¿En qué escenario específico preferirías el segundo?

useEffect es asíncrono y se ejecuta después de que el navegador haya pintado en pantalla, evitando bloquear el renderizado visual. En cambio, useLayoutEffect se ejecuta de forma síncrona después de todas las mutaciones del DOM pero antes de que el navegador pinte. Lo usaría si necesito medir la posición de un elemento y ajustar el estilo antes de que el usuario vea el cambio, evitando parpadeos visuales.

Observa este bloque de código. ¿Notas algún problema potencial de rendimiento o fugas de memoria?

useEffect(() => {
  const timer = setInterval(() => {
    console.log('Tick');
  }, 1000);
}, []);

Sí, falta la función de limpieza (cleanup function). El intervalo seguirá ejecutándose incluso si el componente se desmonta, causando una fuga de memoria. Debería retornar una función que llame a clearInterval(timer).
